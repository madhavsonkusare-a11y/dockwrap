01 · Material study

Grain should be felt before it is noticed.

Only the orange square changes. The improved treatments separate surface tone, fine grain, and rim light instead of asking one noise layer to create all the depth.

04 · Rendering resilience

A static fallback keeps the same temperature.

The fallback is a 512 px transparent bake of the approved mark. It is deterministic, offline, and visually identical to the source render—without runtime filter work.
